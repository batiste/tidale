
# Rules

Avoid verbose prose, be concise.
Cleanup duplicate content. We do not want to repeat ourself. If a rule is already explained, do not explain it again.
Raise inconsistencies in terminology or in the rules, do not let them persist. Ask for clarification if needed.
When you make a change, make sure it is consistent with the rest of the rules and that the change is done and consistent in all files (deck.html, rules.html, concept.html, board.html).

Repeating is not adding clarity. If a rule is already explained, do not explain it again. If a rule is explained in one place, reference it in other places instead of repeating it. If a rules is not clear enough, do not add another explanation in another place, instead, clarify the original explanation.
